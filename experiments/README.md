# experiments/

This folder contains all outputs produced by inference and evaluation scripts.

```
experiments/
├── 📁 outputs/             # Raw model responses
│   └── {model}/
│       └── {prompt_type}/
│           └── run_{id}/   # One JSON file per run
├── 📁 evaluations/         # CSV summaries of accuracy and bias metrics
├── 📁 metrics/             # Prompt structural and readability metrics
└── 📁 quality_checks/      # QA reports for LLM-rewritten prompt variants
```

---

## outputs/

Raw model responses are organized hierarchically by model, prompt type, and run:

```
outputs/
├── llama31_8b/
│   ├── baseline/
│   │   ├── run_01/
│   │   ├── run_02/
│   │   └── ...
│   ├── role_based/
│   ├── chain_of_thought/
│   ├── attribute_early/
│   └── attribute_late/
├── qwen3_8b/
└── ministral3_8b/
```

## evaluations/

| File | Description |
|---|---|
| `output_metrics_by_run.csv` | Per-run metrics for each model and prompt type |
| `global_metrics_summary.csv` | Mean, std, min, max across runs for each model–strategy combination |
| `category_metrics_by_run.csv` | Per-run metrics broken down by BBQ bias category |
| `category_metrics_summary.csv` | Aggregated category-level metrics across runs |
| `invalid_outputs.csv` | Records of invalid model responses for manual inspection |
| `prompt_metrics.csv` | Structural and readability measures for all prompt variants |

### Output Metrics Columns

| Column | Description |
|---|---|
| `accuracy` | Proportion of correct answers among valid predictions |
| `unknown_ratio` | Proportion of valid predictions selecting the *unknown* option |
| `sdis` | Stereotype Direction Bias Score (−1 to +1) |
| `ber_nonaligned` | Biased Error Rate on non-aligned instances |
| `delta_acc` | Accuracy gap: Acc(non-aligned) − Acc(aligned) |

## metrics/

Contains `prompt_metrics.csv` with linguistic and structural measures computed on each prompt variant. Columns include `token_count`, `sentence_count`, `average_sentence_length`, `flesch_reading_ease`, `gunning_fog_index`, `yules_k`, `noun_count`, `verb_count`, and `adjective_count`.

## quality_checks/

Contains QA reports for the `attribute_early` and `attribute_late` prompt variants generated by GPT-5-mini. Each report documents structural invariance checks (question, answer options, and labels preserved) and semantic similarity scores (cosine similarity via `all-MiniLM-L6-v2`). Rewrites with similarity below 0.90 were flagged for regeneration.
